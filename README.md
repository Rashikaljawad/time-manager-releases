# Time Manager

A reliable, smart, and fully offline Alarm & Timer app for Android.

## Download

Go to the [Releases](../../releases) section and download `app-release.apk` from the latest version (**V1.0.0**).

## Highlights

- **Offline & Private:** No internet required, zero ads.
- **Smart Alarm:** Custom repeat days, custom tones & labels, full-screen lock alert with snooze, reboot protection, and easy management.
- **Precision Timer:** Custom duration scroll pickers, quick add (`+1m`, `+5m`, `+10m`), and background countdown with pause/resume.
- **Permission Wizard:** One-tap setup for notifications, lock screen overlays, and battery optimizations.
- **Clean UI:** Built with modern Android Material Design.

## Feedback & Bug Reports

If you experience any issues (especially alarms not firing, any other features not working on your device, or anything unexpected), please open an issue or leave a comment. Let us know!
